PIN 测试覆盖五分钟有效期、刷新挑战失效、单次使用、证明重放拒绝、服务端证明验证、加密数据篡改拒绝、证书绑定、畸形 JSON 和超长整数、每分钟请求限制，以及五次错误后的冷却不能通过刷新 PIN 绕过。安卓另外验证以 0 开头的 PIN、输入长度、错误服务端证明、错误或变化的 TLS 证书及保存授权之前的失败处理。

主程序手机连接页使用应用自身截图模式检查了浅色、深色和最小窗口布局。安卓测试在 JVM 上运行实际应用传输与配对代码，未连接安卓真机；Android Keystore、真实蓝牙配对、手机系统权限弹窗和不同路由器的广播行为仍需在实际设备上验证。本机蓝牙监听已成功启动，蓝牙和 HTTPS 使用同一配对逻辑。

所有自动测试使用隔离配置、临时子进程和临时文件。公开验证包仅包含去除本机身份的检查记录，不包含六位 PIN、连接密钥、证书私钥、完整监控快照或安卓发布签名密钥。
