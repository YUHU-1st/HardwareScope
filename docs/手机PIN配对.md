# 手机六位 PIN 配对

适用版本：Windows 1.3.0、Android 1.1.0。电脑和手机都需更新；已有手机保存的授权仍可用于重连。

## 局域网

在电脑端「手机连接」启用局域网连接。手机和电脑连接同一个 Wi-Fi / 局域网，在安卓端查找并选择本电脑，输入电脑显示的六位 PIN 即可配对连接。PIN 可以以 0 开头，需完整输入六位。

查找使用 UDP 47832，实际数据使用电脑设置的 HTTPS 端口，默认 TCP 47831。若找不到电脑，请检查 Windows 专用网络防火墙和路由器客户端隔离；安装目录的 `scripts/Enable-LanFirewall.ps1` 只允许专用网络中的本地子网连接与电脑发现。首次 PIN 配对限于同一网络子网。

## 蓝牙

先在 Windows 与 Android 系统设置中完成蓝牙配对，在电脑端启用蓝牙连接。安卓端选择已配对电脑，再输入相同的六位 PIN。Android 12 及以上需授予附近设备权限。应用 PIN 验证在系统蓝牙配对之后进行。

## 授权与重连

PIN 有效期为五分钟，配对成功后立即失效。要配对另一台手机，在电脑端生成新 PIN；已配对手机的授权保持有效。手机安全保存授权，后续可直接重连，不需要再次输入 PIN。

电脑端「撤销手机授权」会撤销所有手机，并使正在进行的配对失效；之后需生成新 PIN 重新配对。忘记某台电脑时也可在手机端清除保存的连接。配对不自动打开进程控制权限，是否允许手机调整优先级、结束进程或修改设置仍由电脑端决定。

## 验证方式

PIN 不作为永久访问密钥，也不在网络上传输。两端使用 Bouncy Castle 的 SRP-6a 密码认证密钥交换（3072 位组、SHA-256）验证 PIN，然后通过 AES-256-GCM 加密交换强随机授权凭据和电脑证书指纹。手机确认服务端证明及证书绑定后才保存授权，并对后续 HTTPS 请求固定该证书。蓝牙使用已认证、加密的系统 RFCOMM 通道和同样的 PIN 验证协议。

每个挑战只使用一次，挑战三十秒过期。配对入口限制请求速率与待处理挑战数量；错误验证达到限制后暂时锁定，生成新 PIN 不会取消限制。PIN 只保留在当前电脑进程内，不保存到设置文件、手机存储或日志中。电脑服务空闲时不扫描局域网，手机仅在查找电脑时短时发送发现请求。
