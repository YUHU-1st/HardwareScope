# 指标、权限与真实性

硬件视界按主板、CPU、GPU、NPU、内存、显存、网卡和存储分类。每个传感器带有来源；没有读取到的数据保留为空并说明原因，空值不等于零。

| 项目 | 读取方式与适用范围 |
|---|---|
| 主板 / CPU 温度、功耗、风扇、频率 | LibreHardwareMonitor 读取硬件已开放的传感器。通常需要管理员权限；笔记本 EC、厂商驱动、BIOS 和 Windows 安全策略可能限制读取。不会关闭 Windows 驱动安全保护。 |
| CPU 占用 | Windows 系统 CPU 时间差，进程占用除以逻辑处理器数；与采用不同归一化方式的工具可能不同。 |
| NVIDIA GPU / 显存 | 驱动 NVML 直接读取温度、利用率、时钟、显存、功率及性能限制原因；其它显卡由 LibreHardwareMonitor 与 Windows 性能计数器覆盖。 |
| GPU 性能限制 | 独立显示驱动报告的功率、温度、应用时钟等原因；空闲降频单独显示，不作为过热证据。 |
| 风扇 | RPM 和额定百分比明确区分。NVML 的风扇百分比不会伪装为转速；很多笔记本风扇由 EC 管理而不向 NVML 开放。 |
| NPU | DXCore 计算适配器、PnP 清单以及驱动开放的计算 / 神经引擎计数器。没有 NPU 时显示未发现设备；有设备但无计数器时明确不可读。GPU AI 运算不会直接当成独立 NPU。 |
| 内存 | Windows 物理内存使用量及 WMI 配置速率；DDR 数据率 MT/s 与物理 MHz 区分。已启用 LibreHardwareMonitor 的 DIMM 温度读取，依赖模块温度传感器、SMBus 和底层驱动访问权限；不能用 CPU 温度替代。 |
| NVMe 存储温度 | Windows 只读存储接口获取 NVMe SMART 复合温度及独立温度传感器；标准权限优先尝试此接口。管理员模式也会读取 LibreHardwareMonitor 开放的存储指标。来源注明刷新周期；报警 / 临界温度是阈值，列为其他指标，不进入实时温度总览。 |
| 网卡 | 真实累计字节差计算收发速率，同时显示链路速率。链路 Mbps 不作为网卡芯片频率。 |
| 应用 CPU / 内存 / GPU / NPU / 显存 | Windows 进程信息、I/O 计数器和驱动性能计数器；不可访问进程或不支持的设备指标会明确缺失。 |
| 应用 I/O | 进程累计读写字节的差值，包含文件、设备等 I/O，不宣称全部是物理磁盘吞吐。 |
| 应用网络 | 管理员模式启动 Windows ETW，仅监听 TCP/UDP 的 IPv4/IPv6 收发字节事件，合计后按时间计算进程网络速率；标准权限或 Windows 拒绝采集时显示不可用，网卡总吞吐仍可查看。没有用进程 I/O 冒充网络。该项管理员实机验证状态见验证报告。 |

超频只采用可验证的设置证据。CPU 睿频、GPU Boost 和超过标称基础时钟都不能独立证明超频；NVIDIA 驱动支持时读取核心 / 显存设置偏移，并显示 MHz。没有可验证的基准不计算虚假的超频百分比。偏移为零也不排除 BIOS 或电压频率曲线调整。

调优页识别正在运行的 MSI Afterburner、Ryzen Master、XTU、ThrottleStop 等工具，并显示具体进程证据。Windows、NVML 和普通主板接口没有统一的「最后修改参数的软件」记录，因此检测到软件只表明它在运行，不能确定当前超频归属。

优先级操作针对 CPU 调度优先级；不会更改显卡功率限制、BIOS 或设备时钟。结束进程只结束选中的实例，可能丢失其未保存数据，界面会要求确认。系统关键进程、其他登录会话和监控软件自身受到保护；已经重启、PID 被重用的进程需要重新选择。

关闭窗口后托盘继续运行是当前用户会话内的后台应用，监控采集与手机连接保持运行；不是 Windows Service，也不保证注销后运行。完全退出请使用托盘菜单。开机自启指当前用户登录时启动。

默认两秒采样，支持 1–10 秒。历史曲线保存在内存，手机退到后台暂停轮询；不持续向磁盘写入大体量日志。监控本身的 CPU、内存与采样耗时在界面中可见。实测开销和已读到的传感器记录见交付的验证报告。

Windows 和安卓总览都逐设备显示温度及不可读原因。CPU / DIMM 底层读取因权限被拒绝时，与管理员模式下设备仍未提供温度分开说明；主板、实体网卡、虚拟网卡、未检测到的 NPU 也有对应能力说明。多个温度源保留名称和来源，选择温度读数可查看该传感器曲线。

技术依据：[LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)、[NVIDIA NVML](https://developer.nvidia.com/management-library-nvml)、[Windows 性能计数器](https://learn.microsoft.com/en-us/windows/win32/perfctrs/about-performance-counters)、[Microsoft NPU 开发文档](https://learn.microsoft.com/en-us/windows/ai/npu-devices/)。
