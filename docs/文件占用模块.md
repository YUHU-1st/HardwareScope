# HardwareScope FileGuard 文件占用模块 1.1.0

独立安装包仅包含原生 Windows 程序，不需要 .NET、浏览器运行库、驱动或联网账号。支持 Windows 10/11 x64。HardwareScope 1.2.0 提供「文件占用」页面，并附带同一独立模块安装包。

## 界面主题

窗口右上角提供「跟随系统」「浅色」「深色」三项选择，选择后立即保存，并与 HardwareScope 主程序共享。默认跟随 Windows 应用颜色模式；手动选择后系统主题变化不会覆盖。主题使用 Windows 事件通知更新，后台服务不加载界面，不增加主题轮询。

## 安装和右键使用

运行 `HardwareScope-FileGuard-1.1.0-windows-x64-setup.exe`，接受管理员授权。默认安装到受保护的 `Program Files\HardwareScope FileGuard`，注册文件和文件夹右键菜单，并安装 `HardwareScopeFileGuard` 服务。安装时可以取消「开机自动启动」；安装后也可在模块窗口点击「开机自启」或「手动启动」修改。自动启动使用延迟启动，降低开机阶段的影响。

右键文件选择「查看文件占用」，右键文件夹选择「查看文件夹占用」。Windows 11 的经典菜单项在「显示更多选项」中，也可按 Shift+F10。窗口列出占用应用、PID、占用类型和实际文件路径；一个进程打开多个文件句柄时会显示多行。文件夹扫描按打开句柄的路径筛选，不递归读取磁盘中的文件内容。

普通权限只列出和处理自己的进程。检查其他用户或管理员应用时，点击「以管理员身份查看」并接受 Windows 授权。服务不会为普通用户任意执行管理员操作。文件或文件夹本身的访问权限也会检查。

## 解除占用

勾选需要处理的行，再选择操作：

- **释放所选句柄**：强制关闭勾选的文件句柄，应用进程继续运行。应用可能发生错误、丢失未保存数据或崩溃；请先保存工作。只处理查询中选择的句柄，操作前再次检查进程创建时间、句柄对象和文件路径。Windows 没有原子化的「确认对象并关闭另一进程句柄」接口，极短时间内句柄复用的竞争无法完全消除。
- **结束所选进程**：立即结束勾选进程，释放它持有的资源；未保存数据会丢失。操作前重新检查进程实例和占用关系，不能用旧 PID 列表结束后来复用该 PID 的进程。

每次操作都需要在窗口确认，默认选「否」。操作后刷新当前占用；如果应用立即重新打开文件，新句柄会再次显示，不会自动反复关闭。进程的关键系统属性和系统进程名称会阻止危险操作。

文件映射或正在运行的 EXE/DLL 不一定具有可直接关闭的文件句柄；可结束对应应用，但不能保证单独释放映射。受保护进程、系统/内核驱动、安全软件和某些网络文件无法处理时会显示限制或超时。没有发现占用不代表所有内核占用都已经排除，也不会自动删除、移动或修改文件。

## 安静后台运行

后台服务没有窗口、终端或托盘图标，不定期扫描、不上传数据、不访问网络，也不持续写日志。只有用户查询或操作时才启动临时工作进程，处理结束即退出；请求设有超时限制。右键菜单只在用户点击时启动查看窗口。停止服务后可使用当前权限查询；退出查看窗口后，后台服务仍可等待下一次请求。

HardwareScope 的性能监控仍按它原有的托盘设置运行；文件占用服务单独运行，不要求性能监控主窗口开启。完整安装程序默认安装独立模块。卸载 HardwareScope 会保留独立模块；需要彻底移除时在 Windows「已安装的应用」中另外卸载 HardwareScope FileGuard，它会先停止、删除服务，再移除右键菜单和文件。

免安装 ZIP 支持当前权限的按需查询和结束自己的占用进程，但不注册服务或右键菜单。Windows 11 在普通权限下隐藏句柄对象身份时，释放句柄按钮不可用；使用已安装的后台服务或以管理员身份查看才能安全核验句柄。服务安装必须从受保护的 Program Files 目录执行。

## 构建与验证

`pwsh -File scripts/build-fileguard.ps1` 使用 Visual Studio 2022 C++ Build Tools、Windows SDK 和 Inno Setup 6，编译静态运行库的 x64 原生程序、运行隔离测试、生成独立安装包与免安装 ZIP。完整 Windows 交付使用 `scripts/build-windows.ps1`，同时构建、验证和打包模块。

管理员查询会跳过禁止操作的系统进程句柄；文件查询可补充 Windows 能识别的受保护占用，目录查询可能无法列出这类系统占用。服务返回带密钥的句柄身份校验值，不暴露原始内核对象地址。
