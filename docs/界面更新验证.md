## 界面与安装

使用应用自身的截图模式检查了主程序全部七页的浅色和深色界面，并检查最小窗口下的导航、硬件详情、进程、设置及文件占用页。FileGuard 检查了两种主题、最小窗口和真实临时文件占用行。公开预览只展示性能总览与空占用列表，见 [界面与主题](https://github.com/YUHU-1st/HardwareScope/blob/main/docs/界面与主题.md)。系统模式的浅色及深色分支通过隔离设置验证；本次没有修改当前用户的 Windows 全局颜色设置。

完整安装包在已有安装上静默升级成功：主程序 1.2.0、FileGuard 1.1.0、文件与文件夹右键命令、自动延迟启动服务均已检查。升级前已备份用户数据；升级后原有设置、设置备份、连接密钥和证书文件的 SHA-256 均保持一致。

服务运行在会话 0，没有窗口。测试完成后的 12 秒空闲采样记录 CPU 时间增量 0 ms、工作集 10,514,432 字节（约 10.03 MiB）、私有内存 1,650,688 字节（约 1.57 MiB）。这是一次实机样本，查询文件时的开销取决于进程和句柄数量；服务空闲时不主动扫描，主题处理只在用户界面运行。

本次完成了 Release 构建和自包含安装包生成。发布同时提供完整安装版、完整免安装版、原生 FileGuard 轻量安装版与免安装版、源码、验证记录及 SHA-256 清单。
